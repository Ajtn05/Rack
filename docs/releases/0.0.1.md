# Rack 0.0.1 — First Preview

Rack brings a classic hi-fi stack to your Mac's audio. Equalize your music,
balance individual apps, add warmth and space, and watch the signal through
a choice of live analyzers.

## Included

- Ten-band graphic EQ, bass/treble, preamp, balance, and boost controls.
- Tape/tube saturation, compressor, limiter, reverb, echo, stereo width,
  and headphone crossfeed.
- Per-app volume and mute.
- Seven analyzer views, plus an off mode.
- Output selection and optional microphone monitoring with feedback protection.
- Saved presets, automatic device/app switching rules, and session restoration.
- Thirteen themes and configurable panel layout.
- Menu bar controls, launch at login, and global bypass/power/window shortcuts.

## Install

Requires **macOS 14.4 or later**. The universal archive contains native
**Apple silicon (`arm64`) and Intel (`x86_64`)** executables.

1. Download `Rack-0.0.1-macOS-universal-preview.zip` and extract it.
2. Move `Rack.app` to Applications and open it.
3. Grant system audio capture permission when prompted.

This preview is **ad-hoc signed and not notarized**. macOS Gatekeeper may
block a downloaded copy. If you trust the build, use **Open Anyway** in
**System Settings → Privacy & Security**, following
[Apple's instructions](https://support.apple.com/en-us/102445). Microphone permission is only
needed if you enable live monitoring.

Audio is processed on your Mac and is never recorded, stored, or uploaded.

## Validation and preview scope

Release preparation checks the audio/model suites in debug and optimized
builds, module boundaries, test registration, theme rendering, universal
binary architecture, release entitlements, code signature, ZIP integrity,
and SHA-256 checksum. The local validation record is in
`docs/releases/0.0.1-validation.md` in the source repository.

The Intel slice is cross-compiled; it has not been tested on an Intel Mac.
Live audio capture, permission prompts, physical device changes, microphone
monitoring, and listening tests need a manual check before publication.
This is an early preview; report problems with your macOS version, output
device, and the steps that reproduce them.

The SHA-256 checksum is supplied in `SHA256SUMS`; `release-info.json` records
the build and source state.
